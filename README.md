## 🚀 Cómo abrir los proyectos

Para ejecutar cualquiera de los laboratorios en tu máquina local:

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
    ```
2.  **Abrir en Unity Hub:**
    * Abre *Unity Hub*.
    * Haz clic en "Add project from disk".
    * Selecciona la carpeta del laboratorio específico que deseas abrir.
3.  **Configuración:**
    * Asegúrate de tener instalada la versión de Unity correspondiente al proyecto.
    * Espera a que Unity importe todos los *Assets* (esto puede tardar unos minutos la primera vez).
